# 🛒 ShopNest E-Commerce

A full-stack E-Commerce web application built using Spring Boot, Spring Security, Spring Data JPA, Thymeleaf, MySQL, and Maven.

## Features

- User Registration & Login
- Spring Security Authentication
- Product Catalog
- Shopping Cart
- Order Management
- MySQL Database Integration
- Responsive User Interface

## Technologies Used

- Java 17
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Maven
- HTML
- CSS
- JavaScript

## Run the Project

1. Clone the repository.
2. Configure MySQL in `application.properties`.
3. Run:

```bash
mvn spring-boot:run
```

4. Open:

```
http://localhost:8080
```
